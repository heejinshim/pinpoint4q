# 2026년도 하반기(4Q) Pin Point 판촉방안 — 대전·세종·충남

대전·세종·충남의 차량 등록과 주민등록 인구를 시도 › 시군구 › 읍면동 단위로 묶어, **어디서(지역·동), 누구에게(타겟 고객), 무엇을(차종), 어떻게(판촉방안)** 팔지 정리한 대시보드입니다.

- 사이트: `docs/` — 표지(`index.html`) + 7개 장 + 판촉 목표 시뮬레이터 + 출처. GitHub Pages 주소: https://heejinshim.github.io/pinpoint4q/
- 핵심 결론: 4Q 판촉 자원은 **세종시·대전 유성구**에 먼저 집중합니다. 2순위는 대전 서구·천안·아산입니다. 12월은 HEV·EV 세제 혜택을 앞세운 ‘연내 출고’ 마감 캠페인이 핵심입니다.

## 폴더

```
data/raw/          원본 파일 (주민등록 인구 CSV, KOSIS 자동차등록대수 xlsx)
data/processed/    스크립트가 만든 집계 CSV + 2025년 신규 등록 집계
scripts/           집계·빌드 스크립트
docs/              대시보드 (index.html, app.js, style.css, data.js)
```

## 데이터 갱신

```bash
pip install pandas openpyxl
./build.sh                # 아래 세 단계를 한 번에 실행
```

1. `scripts/build_population.py`: 행정안전부 주민등록 인구 CSV(읍면동, 1세 단위, cp949)를 읍면동·시군구별 연령대 비중과 영패밀리 지수로 바꿉니다. 새 달 파일은 `data/raw/population_YYYYMMDD.csv`로 넣으면 가장 최근 파일을 씁니다.
2. `scripts/build_registration.py`: KOSIS 「자동차등록대수현황 시도별」(DT_MLTM_5498) 엑셀을 시군구 × 차종 × 용도의 long 형식으로 바꿉니다. **대전·세종·충남 시군구를 모두 선택해서** 내려받은 파일이 필요합니다.
3. `scripts/build_site.py`: 집계 CSV를 묶어 `docs/data.js`를 만듭니다.

## GitHub Pages 배포

Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / `/docs`.
무료 계정은 공개 저장소에서만 Pages를 쓸 수 있습니다. 공개로 바꾸면 `data/raw`의 원본도 보이니, 필요하면 원본을 빼고 `docs/`만 공개하세요.

## 지표 정의

- **영패밀리 지수** = 0–9세 비중 + 30–44세 비중 (SUV·MPV·HEV 가족차 판촉 후보 선별용)
- **특화지수** = 지역 점유율 ÷ 벤치마크 점유율 (1보다 크면 그 지역에서 유독 잘 팔림)
- **벤치마크** = 자료가 온전한 전국 시군구 합계, 제주(렌터카) 제외
- 연료 구분은 모델명 기준(HEV 표기, EV·아이오닉·테슬라 등)

## 데이터 출처와 한계

- 인구: 행정안전부 주민등록 인구, 2026년 9월 30일 기준(읍면동 317곳).
- 2025년 신규 등록: 대전·세종은 전체가 있고, 충남은 계룡·공주·금산만 차종 상세가 온전합니다. 천안·아산 등은 인구 구조로 추정했습니다.
- 전기차 추이: ‘대전충남 소속’ 행(세종 포함 추정), 2026은 연중 누적.
- KOSIS 자동차등록대수(2026.08): 지금 받은 파일에는 서울·부산·대구·인천·전남광주만 있고 대전·세종·충남이 없습니다. 다시 내려받으면 파서가 그대로 처리합니다.
- 세제: 승용차 개소세 인하는 2026년 6월 30일에 끝났습니다. HEV·EV 감면은 연말 출고분까지입니다([겟차, 2026.6.30](https://web.getcha.kr/articles/trend-car-excise-tax-end-2026)). 연장 여부는 확인이 필요합니다.
- 타겟·판촉방안은 위 지표를 바탕으로 한 분석 제안입니다.
